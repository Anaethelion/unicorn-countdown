# unicorn-countdown 🦄✨

A sparkly, responsive countdown to **Monday at 5:30 PM** (your local time).

- Huge glass-card countdown with rainbow-flowing digits
- A rainbow arch across the sky, lit up by a unicorn flying along it
- Starfield with parallax, shooting stars, cursor/touch sparkles, click bursts
- Week-progress bar with a unicorn rider
- Fireworks when the clock hits zero
- Responsive from phones (portrait and landscape) to TVs; respects reduced motion

## Run it

Single file, no build step. Open `index.html` in a browser.

## Change the target

Edit `nextTarget()` in the script: day of week (`1` = Monday) and the hour/minute in `setHours(17, 30, 0, 0)`.
